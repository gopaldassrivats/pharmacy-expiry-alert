# 💊 Pharmacy Expiry Alert System

A smart web-based system that helps users track medicine expiry dates and receive timely alerts via notifications.

---

## 🚀 Features

* 📅 Track expiry dates of medicines
* 🔔 Automated alerts via Email/SMS
* 🧾 Add, update, and delete medicine records
* 📊 User-friendly dashboard for inventory management
* 🤖 Rule-based chatbot for treatment suggestions

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python (Flask/Django)
* **Database:** MySQL
* **APIs:** SMS/Email Notification Integration

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/gopaldassrivats/pharmacy-expiry-alert.git
   ```

2. Navigate to the project folder:

   ```bash
   cd pharmacy-expiry-alert
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

---

## 🎯 Use Case

This system helps individuals, pharmacies, and hospitals avoid using expired medicines by providing timely alerts and efficient inventory management.
